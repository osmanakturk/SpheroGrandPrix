# Rule-Based and HSV-Color-Based Classical CV Segmentation and Tracking System Version 2

## English

This project is a classical computer vision system that performs **object segmentation and tracking** based on **predefined HSV color ranges** and **rule-based logic**.

The system uses OpenCV techniques such as:
- HSV color filtering
- CLAHE contrast enhancement
- Bilateral filtering and median blur
- Morphological operations (open/close)
- Contour detection
- Circle fitting and object annotation
- Optional debug visualization

It is designed to detect and track Sphero Bolt robots or other colored objects in a video or live camera feed.  
No machine learning models are used – the system is fully based on pixel-level color rules and geometric heuristics.

## Nederlands

Dit project is een klassiek computer vision-systeem dat **objectsegmentatie en tracking** uitvoert op basis van **vooraf gedefinieerde HSV-kleurbereiken** en **regelgebaseerde logica**.

Het systeem maakt gebruik van OpenCV-technieken zoals:
- HSV-kleurfiltering
- CLAHE-contrastversterking
- Bilaterale filtering en mediane blur
- Morfologische operaties (open/close)
- Contourdetectie
- Cirkelpassing en objectannotatie
- Optionele debugvisualisatie

Het is ontworpen voor het detecteren en volgen van Sphero Bolt-robots of andere gekleurde objecten in video’s of live camerabeelden.  
Er worden geen machine learning modellen gebruikt – het systeem is volledig gebaseerd op kleurregels en geometrische logica op pixelniveau.
